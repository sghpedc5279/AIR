### 7.1　档案数据隐私保护

- **《个人信息保护法》**：处理敏感个人信息须有法定理由并去标识化；档案中的个人履历、健康、政治面貌属敏感信息。
- **去标识化与匿名化**：开放档案前对姓名、身份证号等做脱敏，但须保留研究可用性（如保留年代、地域粒度）。
- **授权与最小化**：采集与利用遵循"目的限定、最小必要"。

### 7.2　AI 伦理应用

- **算法偏见**：训练数据偏向某群体，可能导致分类/检索不公（如某类档案被系统性低估）。
- **可解释性**：自动分类、推荐结果应可解释，不能"黑箱决策"影响查档权益。
- **自动化决策的边界**：涉及开放/不开放、密级判定的关键决策，须保留人工终审，AI 仅作辅助。

### 7.3　开放与保密的平衡

- **《档案法》**：规定档案封闭期与开放利用；涉密、未到开放期档案依法不开放。
- **分级分类**：按密级、敏感程度分层管理，智能系统须内置权限控制。
- **解密与开放**：建立定期解密审查机制，用 AI 辅助识别可开放档案，但解密决定须人工确认。

**实践思路（开放判定辅助）**：

```python
# 概念示例：基于规则+模型辅助判断档案是否可开放
def open_advice(meta):
    if meta["secret_level"] != "公开" and meta["years_since_close"] < 30:
        return "不开放（封闭期内）"
    if meta["contains_pii"] and not meta["de_identified"]:
        return "需脱敏后开放"
    return "建议开放（人工终审）"
```

### 7.7 大模型安全治理与档案合规（V2.0）

把 AI 引入档案，最大风险不在"不准"而在"不可控"。本小节系统梳理档案 AI 的安全治理（来源：最全行业报告《大模型和智能体安全风险治理与防护》、数世咨询《安全优先的大模型》、同济大学《2025 开源大模型法律风险及防范研究报告》、《大模型训练数据安全研究报告》、《大模型时代的内容治理》）：

| 风险 | 表现 | 档案场景对策 |
|---|---|---|
| 幻觉 | 编造不存在的档案内容 | 关键结论须溯到原件；RAG 限域内语料 |
| 数据泄露 | 训练/推理泄露个人隐私 | 脱敏后入模型；私有化部署 |
| 投毒 | 恶意样本污染语料 | 来源审计；人工抽检 |
| 越权 | agent 越权调取涉密档 | 权限分级；人工终审 |
| 版权/法律 | 误用未授权数据训练 | 仅用已授权/开放数据 |

**课堂复现（检索即方法）**：下列代码展示如何直接调用 OpenAlex 与 CrossRef 的免费 API 复现本模块文献检索，强调"可溯源"的研究习惯（无需任何密钥）。

```python
# 复现本节课的文献检索（均为免费开放 API，无需密钥）
import urllib.request, urllib.parse, json
q = 'AI ethics privacy large language model governance'
# 1) OpenAlex：开放学术图谱（聚合期刊/会议/预印本，含被引数）
url_oa = "https://api.openalex.org/works?search=" + urllib.parse.quote(q) + "&per_page=10&sort=cited_by_count:desc"
oa = json.loads(urllib.request.urlopen(url_oa, timeout=30).read())
for w in oa["results"]:
    print("OA", w["publication_year"], w["title"], "->", (w.get("primary_location") or {}).get("source", {}).get("display_name"))
# 2) CrossRef：期刊 DOI 元数据（代表期刊网站 / 电子期刊，可溯到出版社原文）
url_cr = "https://api.crossref.org/works?query=" + urllib.parse.quote(q) + "&rows=10"
cr = json.loads(urllib.request.urlopen(url_cr, timeout=30).read())
for it in cr["message"]["items"]:
    print("CR", (it.get("issued",{}).get("date-parts",[[""]])[0][0]), (it.get("title") or [""])[0])
```

**误用警示**：① 预印本（arXiv）未经同行评审，引用时须标注"preprint"并追踪正式版本；② 被引数仅代表影响力而非结论正确，须回到原文核对方法与数据；③ 商业数据库（Web of Science、Scopus、Elsevier、JSTOR、CNKI 知网、万方、维普等）本环境无订阅权限，无法直连，需通过机构账号在本地获取后再贴入；④ 文献与本节实验的映射是"启发"而非"背书"，落地前需在教材预部署环境中实测。
