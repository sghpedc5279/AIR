### 1.1　档案管理数字化转型的历程与趋势

档案管理的信息化经历了三个递进阶段，理解这一脉络是学习"智能管理"的前提。

**阶段一：数字化（Digitization）**。以"存量数字化、增量电子化"为标志，核心是把纸质档案扫描、条目录入，解决"看得见、查得到"的问题。这一阶段产出的是图像与目录，但数据不可计算。

**阶段二：数据化（Datafication）**。以电子文件单套制、元数据标准化、档案数据仓库为标志，核心是把档案变成结构化、可关联、可统计的数据，解决"算得动"的问题。

**阶段三：智能化（Intelligence）**。以 AI、大模型、知识图谱为标志，核心是从"管"走向"用"、从"存"走向"服"，档案系统能够理解内容、主动推荐、辅助决策。

**趋势判断**：
- 从"以管为主"转向"以用促管"；
- 从"被动查档"转向"主动服务"；
- 从"人工主导"转向"人机协同"；
- 从"单馆孤岛"转向"跨域知识网络"。

> **讯飞知喻实践（专栏）**：讯飞知喻在多个省级档案馆落地"AI 档案大脑"，将 OCR 识别、语音检索、智能编目整合为统一平台，可作为阶段三的典型案例在课堂演示。

### 1.2　智能档案管理的概念框架

**定义。** 智能档案管理，是以人工智能、大数据、知识图谱为支撑，覆盖档案"采集—管理—保存—利用"全生命周期的档案管理新范式。其本质不是用机器替代档案人，而是**放大档案人的认知与服务能力**。

**五技术支柱（讯飞知喻视角）**：

| 技术 | 在档案管理中的作用 | 典型场景 |
|------|------------------|---------|
| OCR 文字识别 | 将扫描图像转为可检索文本 | 历史档案批量转写 |
| ASR 语音识别 | 会议录音、口述档案转写 | 口述史建档 |
| NLP 自然语言处理 | 自动分类、标引、摘要 | 智能编目 |
| 知识图谱 | 实体—关系建模 | 档案关联发现 |
| 大模型 | 问答、生成、辅助决策 | AI 数字人教师 |

**全生命周期智能框架**：

```
采集 ──► 整理 ──► 保管 ──► 利用
 │         │         │         │
OCR/ASR   NLP分类   环境监测   语义检索
         自动标引    AI修复    知识服务
                   长期保存    智能推荐
```

### 1.3　档案数据治理理论

数据是智能管理的基础。没有好的数据治理，AI 只会"garbage in, garbage out"。

**数据治理四大支柱**：

1. **质量（Quality）**：完整性、准确性、一致性、时效性。档案数据治理特别强调**来源可靠**——每份档案的形成背景、流转链条必须可追溯。
2. **标准（Standard）**：遵循 DA/T 系列标准（如 DA/T 25-2022 档案数字化规范）、元数据标准，确保跨系统互操作。
3. **安全（Security）**：分级分类、加密存储、访问控制；平衡开放与保密（见第七部分）。
4. **共享（Sharing）**：在合规前提下破除"数据孤岛"，让档案数据流动起来产生价值。

**档案数据治理的特殊性**：
- **证据价值优先**：治理不能损害档案的原始性与凭证性。
- **长期可读**：格式迁移与仿真保存确保几十年后仍可读。
- **过程可控**：每一次智能处理都应留痕，可审计、可解释。

### 1.8 档案作为数据要素：要素化与可信数据空间（V2.0）

在"数据要素×"国家战略下，档案已从"保管对象"升级为"可配置、可流通、可增值的数据资产"（来源：数据要素（可下载）、AI前沿研究报告、数字治理）：

- **数据资产入表**：档案数据经治理后可作为数据资产核算，参照《一体化政务大数据体系建设指南》《可信数据空间标准体系》。
- **可信数据空间**：在保障主权与合规前提下，档案数据可在"可信数据空间"内授权流通，呼应清华大学《数字政府发展指数》对数据共享开放的评估维度。
- **安全底线**：依《政务数据共享开放安全》要求，开放前须完成分级分类与脱敏。

| 层次 | 目标 | 关键动作 | 对应标准/依据 |
|---|---|---|---|
| 资源化 | 档案变可用数据 | 数字化、元数据、四性检测 | DA/T 31、GB/T 18894 |
| 资产化 | 档案变可计量资产 | 盘点、确权、入表 | 数据资产相关会计规定 |
| 资本化 | 档案变可流通要素 | 授权、脱敏、空间流通 | 可信数据空间标准体系 |

> **为什么重要**：理解"档案=数据要素"，才能解释为何投入智能管理——不是炫技术，而是让沉睡档案产生合规二次价值。

**实践流程**：
1. 列举本馆可开放/须脱敏/须授权三类档案各 3 例；
2. 对"可资产化"档案做数据盘点与确权草图；
3. 设计一项"可信数据空间内授权流通"的最小场景；
4. 标注流通前必须完成的合规动作清单。

**评估要点**：是否把"合规前置"而非"先流通后补救"。

**课堂复现（检索即方法）**：下列代码展示如何直接调用 OpenAlex 与 CrossRef 的免费 API 复现本模块文献检索，强调"可溯源"的研究习惯（无需任何密钥）。

```python
# 复现本节课的文献检索（均为免费开放 API，无需密钥）
import urllib.request, urllib.parse, json
q = 'digital preservation archival science records management'
# 1) OpenAlex：开放学术图谱（聚合期刊/会议/预印本，含被引数）
url_oa = "https://api.openalex.org/works?search=" + urllib.parse.quote(q) + "&per_page=10&sort=cited_by_count:desc"
oa = json.loads(urllib.request.urlopen(url_oa, timeout=30).read())
for w in oa["results"]:
    print("OA", w["publication_year"], w["title"], "->", (w.get("primary_location") or {}).get("source", {}).get("display_name"))
# 2) CrossRef：期刊 DOI 元数据（代表期刊网站 / 电子期刊，可溯到出版社原文）
url_cr = "https://api.crossref.org/works?query=" + urllib.parse.quote(q) + "&rows=10"
cr = json.loads(urllib.request.urlopen(url_cr, timeout=30).read())
for it in cr["message"]["items"]:
    print("CR", (it.get("issued",{}).get("date-parts",[[""]])[0][0]), (it.get("title") or [""])[0])
```

**误用警示**：① 预印本（arXiv）未经同行评审，引用时须标注"preprint"并追踪正式版本；② 被引数仅代表影响力而非结论正确，须回到原文核对方法与数据；③ 商业数据库（Web of Science、Scopus、Elsevier、JSTOR、CNKI 知网、万方、维普等）本环境无订阅权限，无法直连，需通过机构账号在本地获取后再贴入；④ 文献与本节实验的映射是"启发"而非"背书"，落地前需在教材预部署环境中实测。

**与实验衔接**：将上述任一篇文献的方法（如 VLM 文档理解、BERTopic 主题建模、知识图谱问答）对照本模块实验改写数据集或提示词，即可形成有学术依据的结题报告。
