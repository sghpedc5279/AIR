## 第五部分　档案智能保管与保护

> **学习目标**
> - 知识：理解数字档案长期保存的 OAIS 参考模型；掌握载体环境监测与 AI 辅助修复的基本方法。
> - 能力：能设计一份数字档案长期保存策略（格式/迁移/封装）；能描述 AI 图像增强修复的流程与局限。
> - 素养：理解"长期可读"是国家记忆安全的底线；认识 AI 修复"可辅助不可虚构"——修复不得伪造档案内容。

### 5.1　数字档案长期保存策略

数字档案的脆弱性在于**技术过时**：软件不兼容、格式淘汰、载体退化。长期保存的经典框架是 **OAIS（开放档案信息系统）参考模型**。

**三大策略**：
- **格式迁移（Migration）**：定期把旧格式转为当前标准格式（如 TIFF→PDF/A），可能损失某些特性。
- **仿真（Emulation）**：保留原运行环境（虚拟机/模拟器），原样运行旧系统读取档案。
- **封装（Packaging）**：用 METS/PREMIS 把内容、元数据、保存事件打包，确保自描述、自证明。

**数字连续性**：从形成到长期保存全程保持真实、完整、可用、可理解，而非"先丢后补"。

### 5.2　载体与环境智能监测

实体档案与数字载体都需环境监测：
- **实体档案库房**：温湿度、光照、虫害、霉变监测；IoT 传感器实时采集，超限自动预警。
- **数字载体**：存储介质健康度（SMART）、备份完整性校验、异地多活。

**智能预警逻辑**：基于历史数据训练异常检测模型，区分"正常波动"与"真实风险"，减少误报。

### 5.3　AI 辅助修复

AI 修复是"抢救性保护"的利器，但边界清晰——**修复缺损，不虚构内容**。

- **图像增强与去噪**：超分辨率、去模糊、去黄，改善可读性。
- **破损检测**：CV 模型识别撕裂、缺失、水渍区域并标注，供人工补全。
- **文字复原**：对褪色、遮挡文字，基于上下文与同版本文献推断补全，但**补全部分须明确标注**，绝不可伪装成原件。

**实践示例（图像增强的概念流程）**：

```python
# 概念示例：用超分辨率模型增强模糊档案图像
from enhance import SuperResolution
sr = SuperResolution(model="real-esrgan")
restored = sr.upscale("sample/faded_scan.png", scale=4)
sr.save(restored, "sample/faded_scan_enhanced.png")
# 注意：增强仅改善视觉可读性，不能"还原"已丢失信息，标注"AI增强版"
```

> **智能交互（虚拟仿真保管场景）**：学生在仿真库房中扮演保管员，应对"温湿度超标""载体告警""突发水渍"等事件，系统评估其处置是否符合规范；AI 破损检测模块可让学生标注一份破损档案的修复方案。

> **讯飞知喻实践（专栏）**：讯飞知喻的 AI 辅助修复能力覆盖图像增强、文字复原、破损检测，已在历史档案抢救中应用。课堂应强调"AI 增强版"与"原件"的可区分性，防止修复结果被误用为凭证。

### 5.4 思政融入（课程思政）：修复的伦理红线

- 档案修复遵循"最小干预、可逆、可识别"原则；AI 补全内容必须显著标注，不得混入原件。
- "为国守史"要求以最严格标准保障档案长期真实可读，任何伪造都是对国家记忆的背叛。

### 5.7 AI 辅助修复、仿真复制与长期保存格式（V2.0）

AI 在"保管与保护"环节的价值，必须落在**标准合规**之上。本小节把模块五修复思路对接真实档案行业标准（来源：档案行业标准知识库，均为国家档案局发布标准原文）：

| 标准号 | 名称 | 与 AI 保护的关联 |
|---|---|---|
| DA/T 25—2022 | 档案修裱技术规范 | AI 补全/色彩还原须以修裱原则为底线，不掩盖原貌 |
| DA/T 89—2022 | 实物档案数字化规范 | 三维/高清采集为 AI 修复提供基准真值 |
| DA/T 90—2022 | 档案仿真复制工作规范 | AI 生成的仿真件须明确标识"复制" |
| DA/T 99—2024 | 档案数字资源备份实施规范 | AI 增强版与原版须分别备份、可溯源 |
| DA/T 47—2009 | 版式电子文件长期保存格式需求 | 增强结果须存为长期保存格式（OFD/PDF/A） |
| DA/T 70—2018 | 文书类电子档案检测一般要求 | 增强前后"四性检测"指标对照 |

> **铁律**：任何 AI 增强（超分辨率、缺字补全、色彩还原）都**不能替代原件**，且必须标注"AI 增强版"、与原版一并保存、可审计。这既是 DA/T 70 要求，也是档案伦理底线。

**实践流程**：
1. 对一张模糊老照片做超分辨率增强；
2. 按 DA/T 70 列出增强前后应检测指标；
3. 撰写"AI 增强说明"附于档案元数据；
4. 说明若发生争议如何溯源。

**评估要点**：是否落实"原件与增强版分别保存、可审计"。


### 5.8 案例精读：老照片超分辨率+仿真复制合规流程（V2.0 续）

**背景**：把 5.7 标准落到一张实物照片。

**步骤**：
1. 按 DA/T 89 做高清采集（基准真值）；
2. 超分辨率增强，标注"AI 增强版"；
3. 按 DA/T 90 做仿真复制，复制件明示"复制"；
4. 按 DA/T 99 把原版与增强版分别备份；
5. 存为 DA/T 47 长期保存格式。

**产出物**：原版/增强版/仿真件三件套 + "AI 增强说明"（5.7 铁律）。

**课堂复现（检索即方法）**：下列代码展示如何直接调用 OpenAlex 与 CrossRef 的免费 API 复现本模块文献检索，强调"可溯源"的研究习惯（无需任何密钥）。

```python
# 复现本节课的文献检索（均为免费开放 API，无需密钥）
import urllib.request, urllib.parse, json
q = 'digital preservation long term image super resolution restoration'
# 1) OpenAlex：开放学术图谱（聚合期刊/会议/预印本，含被引数）
url_oa = "https://api.openalex.org/works?search=" + urllib.parse.quote(q) + "&per_page=10&sort=cited_by_count:desc"
oa = json.loads(urllib.request.urlopen(url_oa, timeout=30).read())
for w in oa["results"]:
    print("OA", w["publication_year"], w["title"], "->", (w.get("primary_location") or {}).get("source", {}).get("display_name"))
# 2) CrossRef：期刊 DOI 元数据（代表期刊网站 / 电子期刊，可溯到出版社原文）
url_cr = "https://api.crossref.org/works?query=" + urllib.parse.quote(q) + "&rows=10"
cr = json.loads(urllib.request.urlopen(url_cr, timeout=30).read())
for it in cr["message"]["items"]:
    print("CR", (it.get("issued",{}).get("date-parts",[[""]])[0][0]), (it.get("title") or [""])[0])
```

**误用警示**：① 预印本（arXiv）未经同行评审，引用时须标注"preprint"并追踪正式版本；② 被引数仅代表影响力而非结论正确，须回到原文核对方法与数据；③ 商业数据库（Web of Science、Scopus、Elsevier、JSTOR、CNKI 知网、万方、维普等）本环境无订阅权限，无法直连，需通过机构账号在本地获取后再贴入；④ 文献与本节实验的映射是"启发"而非"背书"，落地前需在教材预部署环境中实测。
