> **学习目标**

> - 能力：能用机器学习完成一份档案文本的分类与关键词提取；能评估分类模型的准确率并解释误差来源。
> - 素养：理解"人机协作"在整理中的必要性；警惕自动分类对少数类别、边缘主题的系统性忽略。

### 3.1　档案整理的理论依据

![机器学习自动分类档案概念图](assets/ar/Clean_academic_illustration_of_2026-09-09T07-01-57.png)

整理是把"无序"变"有序"的过程，其依据是**分类体系**与**主题词表**。

- **分类法（体系分类）**：以学科/职能层级组织，如《中国档案分类法》按"大类—属类—小类"展开，适合馆藏排架与宏观检索。
- **主题法（主题标引）**：以概念词（主题词）标引，适合跨类聚合同一主题的档案，如"抗美援朝"可横跨军事、外交、民政多类。
- **二者互补**：分类解决"放在哪"，主题解决"关于什么"。

### 3.2　基于机器学习的自动分类

自动分类把"人工判断归入哪一类"转化为"模型预测概率最大的类"。

**特征工程**：将文本转为向量。
- 词袋（Bag-of-Words）/ TF-IDF：简单、可解释，但忽略词序与语义。
- 词向量（Word2Vec / 句向量 / BERT 嵌入）：捕获语义，"扶贫"与"脱贫"在向量空间更接近。

**常用模型**：
- 传统：朴素贝叶斯、支持向量机（SVM）——小样本稳健。
- 深度学习：BERT 等预训练语言模型——语义强，但需标注数据与算力。

**实践示例（用 sklearn 做档案文本分类）**：

```python
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.svm import SVC
from sklearn.model_selection import train_test_split
from sklearn.metrics import classification_report

# corpus: 已标注的档案文本列表；labels: 对应类别（如 文书/科技/会计/声像）
X_train, X_test, y_train, y_test = train_test_split(corpus, labels, test_size=0.2)

vec = TfidfVectorizer(ngram_range=(1,2), max_features=20000)
X_tr = vec.fit_transform(X_train)
clf = SVC(kernel="linear", probability=True)
clf.fit(X_tr, y_train)

pred = clf.predict(vec.transform(X_test))
print(classification_report(y_test, pred))  # 看各类的 precision/recall
```

**误差解读**：低 recall 的类别往往是样本少、表述特殊的类别（如"基建档案"混在"科技档案"中），需用**主动学习**让人工补充标注这些难例。

> **智能交互（人机协作分类）**：学生可在仿真平台上调整 TF-IDF 的 `ngram_range`、更换模型，实时观察分类准确率和混淆矩阵变化；系统提示"模型把 X 类错分为 Y 类，是否补充 10 条标注？"——体验人机协同迭代。

### 3.3　主题标引与关键词提取

自动标引是给档案自动赋予主题词/关键词。

- **关键短语抽取**：基于 TextRank、TF-IDF 或序列标注（BERT-CRF）抽取最能代表文档的短语。
- **主题词表对齐**：将抽取短语映射到《中国档案主题词表》，保证标引规范、可检索。
- **与分类的区别**：分类给"唯一主类"，标引可给"多个主题词"，更适合多维揭示。

### 3.4　著录自动化

著录是填写元数据字段（题名、责任者、时间、档号等）。

- **字段抽取（NER）**：识别正文中的人名、机构、日期、地点，自动填入对应著录项。
- **档号自动生成**：依据分类方案与排列规则生成档号。
- **人机协作模式**：机器给出"建议著录"，档案人确认/修正，既提速又保真。

> **讯飞知喻实践（专栏）**：讯飞知喻的 NLP 自动分类/标引方案，针对档案语料微调语言模型，在省级档案馆的智能编目中，将单份档案著录时间从数分钟降至秒级，分类准确率达行业领先水平。课堂可对比"纯人工""纯机器""人机协作"三者的质量—效率曲线。

```python
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split
corpus = ["会议纪要关于预算审批……", "人事任免通知……", "科研项目申请书……"]  # 已标注文本

X_train, X_test, y_train, y_test = train_test_split(corpus, labels, test_size=0.3, random_state=42)
vec = TfidfVectorizer(tokenizer=lambda s: list(jieba.cut(s)))
clf = LogisticRegression(); clf.fit(vec.fit_transform(X_train), y_train)
print("准确率:", clf.score(vec.transform(X_test), y_test))
```

```python
# 复现本节课的文献检索（均为免费开放 API，无需密钥）
import urllib.request, urllib.parse, json
q = 'automatic document classification machine learning records'
# 1) OpenAlex：开放学术图谱（聚合期刊/会议/预印本，含被引数）
url_oa = "https://api.openalex.org/works?search=" + urllib.parse.quote(q) + "&per_page=10&sort=cited_by_count:desc"
oa = json.loads(urllib.request.urlopen(url_oa, timeout=30).read())
for w in oa["results"]:
    print("OA", w["publication_year"], w["title"], "->", (w.get("primary_location") or {}).get("source", {}).get("display_name"))
# 2) CrossRef：期刊 DOI 元数据（代表期刊网站 / 电子期刊，可溯到出版社原文）
url_cr = "https://api.crossref.org/works?query=" + urllib.parse.quote(q) + "&rows=10"
cr = json.loads(urllib.request.urlopen(url_cr, timeout=30).read())
for it in cr["message"]["items"]:
    print("CR", (it.get("issued",{}).get("date-parts",[[""]])[0][0]), (it.get("title") or [""])[0])
```
