## 第六部分　档案智能利用与服务

> **学习目标**
> - 知识：理解从"查档"到"知识服务"的范式转变；掌握智能推荐与档案可视化的基本方法。
> - 能力：能设计一个基于标签的档案推荐逻辑；能用时间线/地图/关系图呈现档案知识。
> - 素养：树立"以利用者为中心"的服务观；认识算法推荐可能造成的"信息茧房"与利用不公。

### 6.1　从"查档"到"知识服务"

传统利用是"用户主动查、馆员被动供"。智能利用转向**主动服务**：
- 查档前：基于利用者画像与历史行为，**预推送**可能相关的档案。
- 查档中：语义检索、智能问答降低利用门槛。
- 查档后：知识图谱关联推荐，引导深度利用。

### 6.2　智能推荐系统

推荐解决"用户不知道有什么"的问题。

- **基于内容（Content-based）**：根据用户曾查阅档案的标签（主题、年代、机构）推荐相似标签档案。
- **协同过滤（Collaborative）**：利用"相似利用者看了什么"做推荐。
- **混合推荐**：兼顾个性与多样，避免茧房。

**实践示例（基于标签的内容推荐）**：

```python
# 概念示例：基于标签重合度推荐档案
def recommend(user_tags, archive_db, top_k=5):
    scored = []
    for arc in archive_db:
        overlap = len(set(user_tags) & set(arc["tags"]))
        scored.append((arc["id"], overlap))
    return [i for i,_ in sorted(scored, key=lambda x:-x[1])[:top_k] if _ > 0]

user_tags = {"土地改革", "1950年", "西南地区"}
print(recommend(user_tags, archive_db))
```

### 6.3　档案数据可视化服务

把档案"读"成图，降低理解门槛：
- **时间线**：历史事件、政策演进。
- **地图**：档案地理分布、事件空间演化。
- **关系图**：人物/机构网络（承接第四部分知识图谱）。
- **仪表盘**：利用统计、馆藏结构（可复用 FineBI 等低代码工具）。

### 6.4　AI 利用者咨询（虚拟利用者）

用对话式 AI 模拟"利用者"，训练学生的服务设计能力：
- 学生面对 AI 生成的利用者咨询（"我想找爷爷当年在XX厂的劳模材料"），设计查档路径与答复。
- AI 评估其方案是否覆盖授权、检索、出具证明全流程。

> **讯飞知喻实践（专栏）**：讯飞知喻的推荐系统与可视化服务平台已在档案利用中落地，将利用者从"关键词苦搜"解放为"对话即所得"。课堂可演示"用自然语言问一句，系统返回相关档案+关联图谱+可视化时间线"的完整链路。

### 6.5 思政融入（课程思政）：利用服务中的公平与边界

- 主动推送不应越界披露未开放档案；推荐算法需可解释、可审计，避免利用不公。
- "为民服务"要求服务覆盖不同数字素养的群体，不能只服务于"会用 AI"的人。

1. 算法推荐可能让利用者只看到"想看的"，如何避免档案利用的"信息茧房"？
2. 为县档案馆设计一个"民生档案"智能利用场景（含推荐+可视化+咨询）。
3. 拓展阅读：档案利用服务数字化相关规范与案例。

### 6.8 档案数据可视化、智能编研与档案展览（V2.0）

利用环节正从"查档"走向"主动供给"。V2.0 把可视化、智能编研与展览规范打通（来源：档案行业标准库 DA/T 102—2024、信息可视化、数字人文库 AI 编研资政）：

- **智能编研**：用 LLM 从开放档案自动抽取主题、生成编研素材初稿（如"苏州百年河道治理"时间线），人工润色后形成资政参考。
- **可视化叙事**：将编研结果做成可交互图表/地图，对接模块六利用服务。
- **展览合规**：依 DA/T 102—2024《档案展览工作规范》，展览内容须审定、版权清晰、涉密规避。

> **常见误区**：把 LLM 生成的编研稿直接署名发布。正确做法：LLM 出"素材草稿"，档案员核实每处史实与出处后再定稿——AI 不署名，人对内容负责。

**实践流程**：
1. 选一组开放民生档案；
2. 用 LLM 生成"本地教育档案百年变迁"编研提纲；
3. 按 DA/T 102 自查展览合规项（版权、涉密、署名）；
4. 产出"编研稿合规核查表"。

**评估要点**：编研稿是否逐条标注史料出处、AI 贡献是否透明。

**课堂复现（检索即方法）**：下列代码展示如何直接调用 OpenAlex 与 CrossRef 的免费 API 复现本模块文献检索，强调"可溯源"的研究习惯（无需任何密钥）。

```python
# 复现本节课的文献检索（均为免费开放 API，无需密钥）
import urllib.request, urllib.parse, json
q = 'knowledge graph retrieval augmented generation archives semantic search'
# 1) OpenAlex：开放学术图谱（聚合期刊/会议/预印本，含被引数）
url_oa = "https://api.openalex.org/works?search=" + urllib.parse.quote(q) + "&per_page=10&sort=cited_by_count:desc"
oa = json.loads(urllib.request.urlopen(url_oa, timeout=30).read())
for w in oa["results"]:
    print("OA", w["publication_year"], w["title"], "->", (w.get("primary_location") or {}).get("source", {}).get("display_name"))
# 2) CrossRef：期刊 DOI 元数据（代表期刊网站 / 电子期刊，可溯到出版社原文）
url_cr = "https://api.crossref.org/works?query=" + urllib.parse.quote(q) + "&rows=10"
cr = json.loads(urllib.request.urlopen(url_cr, timeout=30).read())
for it in cr["message"]["items"]:
    print("CR", (it.get("issued",{}).get("date-parts",[[""]])[0][0]), (it.get("title") or [""])[0])
```

**误用警示**：① 预印本（arXiv）未经同行评审，引用时须标注"preprint"并追踪正式版本；② 被引数仅代表影响力而非结论正确，须回到原文核对方法与数据；③ 商业数据库（Web of Science、Scopus、Elsevier、JSTOR、CNKI 知网、万方、维普等）本环境无订阅权限，无法直连，需通过机构账号在本地获取后再贴入；④ 文献与本节实验的映射是"启发"而非"背书"，落地前需在教材预部署环境中实测。
